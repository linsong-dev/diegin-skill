# Data Analysis · 数据诚信规则包（4 条）

> 目标：**结论可溯源、计算可复现**。覆盖来源、备份、异常、公式四个维度。
> 安装与定制见 [总入口](../README.md)。

## 规则明细

| # | 规则 | 严重度 | 触发 | 处置 |
|:-:|:--|:--:|:--|:--|
| 1 | 数据来源标注 | high | 含统计/百分比/趋势但未注明来源 | 警告并要求标注「数据来自 XXX」 |
| 2 | 图表原始数据备份 | medium | 生成图表未保留原始数据 | 要求导出 CSV/JSON |
| 3 | 异常值标注 | high | 数据含异常值（±3σ）未说明 | 要求说明处理方式 |
| 4 | 计算过程可复现 | medium | 含计算结果但未给公式 | 警告并要求公式+中间值 |

## 为什么是这 4 条

- **真伪门**（1/4）：「无来源的数据」是 AI 分析报告中最常见的隐性造假；来源标注是硬要求。
- **可复现性**（2/4）：图表没有原始数据 = 结论无法复核；这是分析工作的最低诚信标准。
- **完整性**（3）：异常值不说明，平均值就会被单点污染；这是统计误读的头号来源。

## 快速试用

```powershell
Copy-Item deploy/domain-examples/data-analysis/rules.json <迭进根>\engine\evo\rules\domain_rules\domain_example_data_analysis.json
```

然后在回复中输出「增长了 20%」而不给来源——迭进应提示「数据来源标注」。
