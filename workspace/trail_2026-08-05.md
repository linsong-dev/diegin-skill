## Hooks 修复（2026-08-05 下午）——攻七反馈闭环真实跑通

### 根因（auto_adopt 从未真正执行）
- post_tool.ps1 L149 `if (Test-Path $prioFile -and $toolExitCode -eq 0)`：`-and` 被 PowerShell 绑定为 `Test-Path` 的命名参数 → 每次抛 `A parameter cannot be found that matches parameter name 'and'`（审计 30+ 条 auto_adopt_error 印证）
- 更深一层：Codex PostToolUse hook 输入**不含 exit_code 字段**，`$toolExitCode` 恒 NULL → 即使修复 -and，`-eq 0` 也永不成立
- 结论：Q4 反馈闭环自写入起从未真正生效

### 修复
- 条件改为 `(Test-Path $prioFile) -and -not $toolError -and ($null -eq $toolExitCode -or $toolExitCode -eq 0)`（与 L307/L341「NULL 视为成功」约定一致）
