# Agent 记忆与进化：迭进 vs Mem0 / Zep / Letta / Claude Code / Codex

> 2026 年，AI Agent 的记忆与自我进化成为最热的方向之一。市面上已有 Mem0、Zep/Graphiti、Letta、LangMem 等通用记忆框架，Claude Code 与 Codex 也各自内置了记忆体系。
> 迭进（Diegin）作为一条独立路线，与它们有何不同？本文从「记忆、纠错、强化、仲裁、断点续接、验证拟真」六个维度做一次诚实的横向对比。

---

## 一、为什么需要横向对比

任何一个声称「AI 自我进化」的系统，都必须先回答一个问题：**它和已有的记忆框架有什么本质不同？**

通用记忆框架（Mem0/Zep/Letta）解决的是「记住」：把对话、偏好、事实沉淀下来，下次检索到。
迭进解决的是另一个问题：**记住之后，怎么让 Agent 不再犯同样的错？**

这是两条不同的赛道。前者是「记忆层」，后者是「行为进化层」。迭进真正的对手不是 Mem0，而是 Claude Code 的 Auto Memory / AutoDream，以及 Codex 的 Memories。

---

## 二、六维横向对比

### 1. 自动记忆：谁在真正「主动记住」

| 方案 | 自动记忆 | 机制 |
|---|---|---|
| Mem0 | ✅ | 外部提取（add_memory），向量+图谱 |
| Zep/Graphiti | ✅ | 时态知识图谱，时效窗口 |
| Letta | ✅ | 分层记忆，OS 式分页 |
| Claude Code | ✅ | Auto Memory：跨会话自动摘要 |
| Codex | ✅ | Memories：闲置 6h 后台摘要 |
| **迭进** | ✅ | **每个 hook 实时写入 + 语义检索注入** |

迭进的记忆写入发生在每个工具调用之后（post_tool），而非等待会话结束——**实时性优于 Codex/Claude 的后台摘要**。

### 2. 行为拦截：谁能在错误发生前「阻止」

这是迭进最独特、也是最容易被忽视的能力。

| 方案 | 行为拦截 | 说明 |
|---|---|---|
| Mem0/Zep/Letta | ❌ | 只提供记忆，不干预行为 |
| Claude Code | ❌ | 记忆仅供参考 |
| Codex | ❌ | AGENTS.md 是静态契约 |
| **迭进** | ✅ | **pre_tool 规则裁决，命中 critical/blocking 直接 exit 1 阻断** |

迭进不是「提醒」，而是**在工具调用前用规则引擎做硬裁决**：命中断言直接阻止执行。这是所有通用记忆框架都没有的。

### 3. 错误自愈验证：谁在错误发生后「确认修好了」

| 方案 | 自愈验证 | 说明 |
|---|---|---|
| Mem0/Zep/Letta | ❌ | 无 |
| Claude Code | ❌ | 无 |
| Codex | ❌ | 无 |
| **迭进** | ✅ | **strikes_db 三犯锁途 + fix_status=verified 闭环** |

迭进的一二不过三机制：同类错误犯 3 次→锁死该路径，直到修复被验证。不是「记下错误」，而是「**追踪到修复确认为止**」。

### 4. 模式强化：谁在成功后「提炼经验」

| 方案 | 模式提炼 | 说明 |
|---|---|---|
| 通用记忆框架 | ❌ | 只记事实 |
| Claude/Codex | ❌ | 不提炼可复用模式 |
| **迭进** | ✅ | **攻七：工具成功→提炼模式→auto_adopt 自动采纳** |

迭进把「成功经验」结构化为可复用的模式，且自动采纳——**这是从「记忆」到「进化」的关键一跃**。

### 5. 断点续接：谁在中断后「接得上」

| 方案 | 断点续接 | 说明 |
|---|---|---|
| 通用记忆框架 | ❌ | 记忆在，任务上下文丢 |
| Claude/Codex | ❌ | 无任务级恢复 |
| **迭进** | ✅ | **恒常门：任务快照+目标+完成标准，跨会话恢复** |

迭进的恒常门把「任务」当一等公民：中断→存快照→恢复时注入三件套（目标/完成标准/待办）。实测 379 个恒常门任务快照可跨会话续接（311 暂停 / 57 完成 / 8 放弃 / 3 阻塞）。

### 6. 验证拟真：谁在「确认系统真的有效」

| 方案 | 验证拟真 | 说明 |
|---|---|---|
| Mem0/Zep | ❌ | 无自检 |
| Letta | ❌ | 无 |
| Claude/Codex | ❌ | 无 |
| **迭进** | ✅ | **自检 16/16 + test_all 33/33 + 去伪存真证据裁决** |

迭进对自己的验证是系统性的：引擎自检 16 项、端到端测试 33 项、每轮去伪存真证据裁决——**它不「声称」有效，而是「验证」有效**。

---

## 三、迭进的定位：不是替代品，是进化层

迭进并不替代 Mem0/Zep/Letta。正确的姿势是：

- **记忆事实** → Mem0 / Zep / Codex Memories
- **记住并复用经验** → 迭进
- **防止重复犯错** → 迭进（行为拦截 + 自愈验证）
- **跨会话任务续接** → 迭进（恒常门）

迭进的价值在于：它把「记忆」升级为「行为进化」，把「AI 会犯错」这件事本身，变成了可治理、可验证、可进化的工程问题。

---

## 四、诚实边界

迭进不是万能的：
- 它是**行为层进化**，不是模型权重进化（不改变模型本身）；
- 它是**单机/单平台**的（不跨机器同步记忆）；
- 它不提供**语义向量检索**（用 n-gram 哈希，语义不如 Mem0 强）；
- 它不做**时态推理**（Zep 的时效窗口更强）。

这些边界，恰恰说明迭进应该与通用记忆框架**互补**，而非竞争。

---

## 五、结论

2026 年的 Agent 记忆赛道，多数玩家在解决「记住」，迭进在解决「不再犯错」。

如果只选一个关键词概括迭进，那就是：**行为进化**。记忆只是它的输入，规则引擎才是它的内核，验证闭环才是它的护城河。

迭进不是又一个记忆框架，而是一个**把 Agent 从「会犯错的工具」进化为「能自我纠错的系统」的进化层**。
